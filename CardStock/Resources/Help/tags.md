**Tags** are topics you put on anything in your site, like *design* or *travel*: any page (a blog post, a product, a project, Home, a category) and any photo or file. Unlike categories, which belong to one collection, one tag can gather all of them.

## Tag a page

In the page's editor, type a tag in **Tags** and press Return (or type a comma). Tags already used on your site show as suggestions while you type, and the tag button next to the field lists them all. Click the × on a tag to take it off.

Tags spelled differently ("iOS", "ios") are the same tag.

## Tag photos and files

On the [Files](cardstock:files) page, select a file and add tags under its details, the same way. Select several files to tag them all at once: the field shows the tags they all have, and adding or removing one changes every selected file. Searching on the Files page (and in **Choose from Site Files…**) finds files by tag too.

File tags are saved in `media.json` in your site folder, so they go to GitHub with the rest of your site when you publish, and show up on your other Macs. The file itself isn't put on your website.

## Tag pages

Each tag gets a page listing everything with it, like `/tags/design/`: its pages, then its photos as a gallery and its other files as links. `/tags/` lists every tag, and tags on item pages link to them. Turn tag pages off in [Tags](cardstock:tags) in Configuration, and tags show as plain words.

Whether an item page shows its tags is up to its collection: see **Tags** under Item Pages in [Collections](cardstock:collections).

## Manage tags

[Tags](cardstock:tags) in Configuration lists every tag with how many pages and files have it. Click a tag to see them (**Show** opens a file on the Files page) and write a **description**, shown at the top of its page. From the … menu:

- **Rename…** changes the tag on every page and file. Renaming it to another tag's name merges the two.
- **Merge Into** moves its pages to another tag.
- **Preview Tag Page** shows its page in the preview.
- **Delete…** takes the tag off every page and file. They stay.

**New Tag…** makes a tag before any page uses it, so it's ready to pick. Its page is published once a page or file has it.
