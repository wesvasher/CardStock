---
title: Use CardStock without GitHub
category: Publishing
summary: Generate the flat HTML yourself and upload it anywhere.
order: 4
---

GitHub is optional. Everything except publishing works without it.

1. Choose **Site → Generate Flat HTML** (⇧⌘B). The [Publishing](cardstock:publishing) page has a **Generate Flat HTML** button too.
2. CardStock writes the finished website into the `public` folder inside your site folder.
3. Click **Show Website Files in Finder** on the Publishing page.
4. Upload everything inside `public` to your web host.

Generate it again after making changes. The Publishing page tells you when the flat HTML is out of date.

> You don't need to generate the flat HTML to see your changes in CardStock. The preview always shows the latest version.
