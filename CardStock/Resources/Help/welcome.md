CardStock is an editor for a simple website: pages, a blog and a small shop. You write in Markdown, see the result live, and publish with one button.

## How it works

- **Your site is a folder.** Every page, blog post and product is a plain Markdown file you can open in any text editor. Nothing is locked inside CardStock.
- **The preview is live.** The right column shows each page as visitors will see it, updating as you type.
- **Publishing is optional.** Link the site to GitHub and CardStock publishes it for you, and a host like Cloudflare Pages puts it online. Or generate the flat HTML and upload the files anywhere yourself.

## The sidebar

| Item | What it's for |
|---|---|
| Start | Shortcuts, your publishing activity and writing stats. Shown when a site opens |
| Status | A site health checklist, how your site gets online (and which steps are set up), and guides for fixing problems. The number next to it is how many things need fixing |
| Configuration | Site Details (title, description and web address), then the look: templates, layouts, fonts, colors, top bar and menu, footer, corners and width |
| Publishing | GitHub, publishing status and hosting help |
| Pages | Every page: static pages, every collection's items, main pages and categories, and link menus |
| Files | Every image and file in your site, ready to copy into a page |
