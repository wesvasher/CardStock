Markdown is plain text with a few symbols for formatting. What you type on the left becomes the page on the right.

## The formatting bar

You don't need to remember the symbols. Select some text and use the bar above the editor:

- **Text style menu (Aa):** Large, Medium or Small heading, Normal Text, or Fine Print
- **Bold** (⌘B), **Italic** (⌘I), Strikethrough and Code
- **Fine Print** (in the Aa menu): small gray text for captions, photo credits and notes. Put it on the line right after an image to use it as a caption
- **Line break** (the return arrow): starts a new line at the cursor without starting a new paragraph, for addresses, poems and lists of short lines. It adds a backslash (`\`) at the end of the line, Markdown's way of writing a line break. Pressing Return once only makes a space on your site; press it twice for a new paragraph
- **Link** (⌘K): select a word, click Link, then type or paste the address
- Bulleted list, Numbered list, Quote and Divider line
- Section break: moves the text after it to the next area of the page's [layout](help:layouts)
- **Image:** insert images at the cursor
- **Emoji** (the smiley face): opens the Mac's emoji picker at the cursor. Search for one or pick from your recent emoji. Emoji are plain text, so they show on your site as they do here. You can also press Control-⌘-Space anywhere in the text.

Click a button again to undo that formatting. The editor shows formatting as you type, with the symbols dimmed.

| Type this | To get |
|---|---|
| `## A heading` | A section heading |
| `### A smaller heading` | A smaller heading |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `[a link](https://example.com)` | [a link](https://example.com) |
| `- item` | A bulleted list |
| `1. step` | A numbered list |
| `> quote` | A quotation |
| `` `code` `` | `code` |
| `---` on its own line | A dividing line |

## Paragraphs

Leave a blank line between paragraphs. A single line break inside a paragraph is ignored.

## Links to your own pages

Use the page's address, starting with `/`:

```
Read more [about me](/pages/about/) or see my [latest posts](/blog/).
```

## Images

Don't type image Markdown by hand. Drag images in instead: see [Add images](help:add-images).
