When a site is linked to GitHub, GitHub keeps every copy in step.

## Set up the second Mac

1. Install CardStock and open it.
2. Choose **Open from GitHub…** on the welcome screen (or **File → Open from GitHub…**).
3. Sign in with a token. Each Mac signs in once, because tokens stay in that Mac's Keychain. You can use the same token or [make a new one](help:connect-github). Signed in to more than one account? Choose whose sites to list.
4. Pick your site, choose where to keep it (Documents → CardStock unless you change it), and click **Download and Open**.

The site arrives with its full history and its GitHub link, ready to edit and publish.

> Downloaded the site as a ZIP from GitHub instead? That works too. A ZIP doesn't include the site's history, so CardStock sets it up again from GitHub the first time you publish.

## Day to day

- CardStock checks GitHub when you switch to it and every few minutes while a site is open.
- When your other Mac has published, **Publishing** in the sidebar gets a purple badge with the number of updates.
- The Publishing page then shows a purple banner: what was published, which posts and pages changed, and what to do. The main button turns purple and reads **Get Latest from GitHub**. Get the latest before you start editing.
- **Publish** always picks up changes from your other Mac before sending yours.

> If both Macs changed the same post, CardStock stops without changing anything and explains what to do.
