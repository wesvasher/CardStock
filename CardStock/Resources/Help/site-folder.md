Everything about a site is in its folder, so you can move, copy or back it up like any other folder.

| In the folder | What it holds |
|---|---|
| `My Site.cardstock` | Double-click to open the site in CardStock |
| `site.json` | Title, description, web address and menu |
| `pages/` | Every page, one Markdown file each: static pages, blog posts, categories, products and link menus. A `type:` line says which. `index.md` is the Home page |
| `media/` | Images and other files. See them all on the [Files](help:files) page |
| `theme/` | The site's design: templates, stylesheet, font, color and layout choices, and web fonts |
| `static/` | Files copied to the site as they are, such as `favicon.ico`, and `_redirects` for old addresses |
| `public/` | The finished website CardStock builds. Don't edit it |

You can edit these files in other apps too. If CardStock is open at the time, choose **Site → Reload from Disk** (⇧⌘R) to see the changes.

To see the folder, choose **Site → Show in Finder**.
