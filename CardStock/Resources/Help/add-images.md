## Three ways to add images

- **Drag** images from Finder or Photos into the text. They go where you drop them.
- **Paste** an image you've copied, such as a screenshot.
- **Click the image button** above the text, then choose:
  - **Choose from Site Files…** to reuse an image already in your site. Click it in the list and it's inserted where the cursor is.
  - **Upload from Mac…** to pick new image files. They go where the cursor is.

## Choose a size

CardStock asks how to add them:

- **Optimized for web (recommended):** saves a version up to 2400 pixels wide for full-screen viewing and a 1200-pixel version for the page. Pages load quickly, and location data from your camera is removed.
- **Full resolution:** keeps the original file. Pages load more slowly. iPhone HEIC photos are converted to JPEG so every browser can show them.

CardStock remembers your choice for next time.

## Add a description

For a single image, write what it shows in **Description**. Screen readers read it aloud, and it's shown as the caption when the image is opened.

## Clicking an image

On the published site, clicking an optimized image opens it full-screen. Visitors can use the arrow keys, the on-screen arrows or a swipe to move through every image on the page, and Escape to close it.

Images are saved in `media/`, in a folder for each page or post.
