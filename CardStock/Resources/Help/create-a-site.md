## Create a new site

1. Choose **File → New Site…** (or press ⇧⌘N).
2. Type a name and pick where to keep it, such as your Documents folder.
3. Click **Create**. CardStock makes a folder with a starter site, including a Home page and a first post, and opens it.

## Open a site

Any of these work:

- **Double-click the site's `.cardstock` file** in Finder. Every site folder has one, named after the site.
- Choose **File → Open Site…** (⌘O) and pick the site folder.
- Drag the `.cardstock` file onto CardStock in the Dock.

CardStock reopens the last site you used each time it starts, on the **Start** screen with shortcuts to common tasks.

> Tip: keep the site folder somewhere that's backed up. If you link it to GitHub, every publish is also a backup.
